POSTO.

POSTO 13 é um jogo independente de terror 3D criado por NILTWON, ambientado em um posto de gasolina cercado por floresta.

Explore a loja, o depósito, as bombas e a região externa. Encontre itens como lanterna, chaves e fusíveis, e tente sobreviver a uma criatura que persegue os jogadores.

“A última parada da madrugada.”

O jogo está disponível para Windows?

Sim. Há uma versão para Windows publicada nas Releases oficiais do GitHub. Clique em Baixar para acessar a versão mais recente disponível.

Tem versão Android?

Sim. O criador publicou um APK para Android. A disponibilidade do download e a identificação da versão são atualizadas conforme as Releases oficiais.

Preciso de internet para jogar?

O multiplayer online utiliza conexão com servidor. O jogo também possui opção de jogar sozinho.

Como atualizo o jogo?

O criador publica novos arquivos em uma nova GitHub Release (por exemplo, v1.0.1). Os botões desta página passam a buscar os arquivos mais recentes de Windows e Android automaticamente.

Quais são os requisitos mínimos?

Os requisitos oficiais de hardware ainda não foram divulgados. Confira a compatibilidade com seu dispositivo antes da instalação.
